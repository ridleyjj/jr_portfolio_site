Jack Ridley

Projects

Scars of Honor MMORPG

I am currently working as the Audio Programmer for Scars of Honor, a free-to-play MMORPG currently in development by Beast Burst Entertainment.

Multi Fader Drone Plugin

Drone Synthesiser made with the JUCE Framework. I wanted to make a fun GUI with JUCE so I created an animated visualiser for the drone.

Sound of Life Plugin

MIDI Plugin made with the JUCE Framework. This plugin creates MIDI messages which are controlled by a grid that obeys the rules of Conway's Game of Life.

Spherical Soundscapes

Solo project exploring interactive audio and generative sound. Built using Unity and Wwise. I used C# scripting in Unity to achieve all game behaviour.

Mechanical Modelling Audio Plugin

Audio Plugin built using C++ in the JUCE framework. This plugin uses physical modelling principles to synthesise mechanical and engine sounds.

Physical Interactions with LeapMotion

I used Unity and C# to create an interface application that connected LeapMotion data to Max/MSP. I then designed 10 distinct audio interactions for this set-up with the aim to create a joyful experience.

Little Mermaid Project

This was a project made with Unreal Engine 4 and Wwise where I took the role of Sound Designer, Audio Programmer, and Games Programmer.

Experiments with p5.js and Tone.js

These are a series of artistic experiments I made using the p5 and Tone javascript libraries to create some fun audio visual interactions for the browser.
